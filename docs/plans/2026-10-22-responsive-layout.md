# OpenYida自定义页面自适应布局优化

计划发布版本：`2026.10.22`。需求编号：`87902201`。

基线：`codex/print-template-87887792`（起点 `b17525592df47b983351d05f5fec32796c07cf66`）。本分支继承前一版本；前置分支持续推进时需再次合并并验证。

这是初始范围与验收计划，功能尚未实现，发布状态未确认。

## 目标

改善自定义页面在桌面、移动端、平台侧栏与 iframe 窄容器中的布局。先审查共享响应式规则、Canvas 模板、导航片段和页面检查器，复用已有 owner，避免只增加零散媒体查询。

## 实现方向

- 根据实际容器宽度与内容最小可用宽度决定布局；媒体查询处理视口语义，容器查询或带清理的 ResizeObserver 处理嵌入容器。
- 让栅格、筛选栏、主辅面板、导航、图表与表格分别降级；紧凑布局保持可操作性，表格局部滚动，正文避免整页溢出。
- 切换断点保持筛选、选中、表单和展开状态；测量副作用有清理与回退，不滥用重挂载。
- 沉淀共享 Skill、可复用示例和有明确价值的 CLI 诊断或生成能力；保持主题、设计意图、业务与 JSX/Canvas 兼容边界。

## 验收

选择有代表性的页面，在至少 360、600、768、1024、1280、1600 px 以及断点前后进行容器测试，并覆盖拖拽缩放、长文本、空态、宽表、筛选栏、抽屉与图表。数值是验收矩阵，不是所有页面的统一断点。使用真实浏览器验证溢出、可点击性、业务状态和布局，补有意义的离线回归。
