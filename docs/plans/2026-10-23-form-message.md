# OpenYida表单消息通知CLI与Skill

计划发布版本：`2026.10.23`。需求编号：`87902241`。

基线：`codex/responsive-layout-20261022-87902201`（起点 `e216d07bb63e78cbf1f91cda4bbcd2f9487b777d`）。本分支继承前一版本；前置分支持续推进时需再次合并并验证。

这是初始范围与验收计划，功能尚未实现，发布状态未确认。

## 目标

将原生表单设置中的消息通知沉淀为可查询、搭建与维护的 CLI 和独立 Skill，说明其使用场景和表单作用域。

## 实现方向

- 先验证原生接口、字段、触发事件、接收对象、内容模板、变量和平台支持边界，再决定实际命令。
- 覆盖平台已证实的查询、创建、修改、更新、启停等操作；不把应用通知、自定义页面消息或外部机器人接口混为同一资源。
- 修改前备份，核对目标和当前版本，避免重复写入，写后回读；未知状态不伪装成功。
- 保留组织版本、权限与接收范围规则，明确配置生效和消息实际送达的区别。

## 验收

离线测试覆盖原生请求、作用域、变量映射、错误、版本冲突和回读。现有业务表单只读研究，配置写入使用明确授权的独立测试目标；真实发送给人或群需要单独授权。CLI、Skill、示例、命令清单、语言包和发布包一起验证。
