# OpenYida方案中心模板AI搭建与启用

计划发布版本：`2026.10.25`。需求编号：`87902266`。

基线：`codex/form-message-20261023-87902241`（起点 `a6b441c95e2dd8788d7395fe9c542709ad1d1483`）。本分支继承前一版本；前置分支持续推进时需再次合并并验证。

这是初始范围与验收计划，功能尚未实现，发布状态未确认。

## 目标

支持通过 CLI 与 Skill 使用方案中心模板的 AI 搭建或直接启用流程，明确两条路径的差异及结果。

## 实现方向

- 先只读核实模板发现、详情、AI 定制、直接启用和创建结果接口，复用既有方案中心能力。
- 处理模板/方案/应用等标识、登录环境、组织权限和版本差异，不猜测原生协议。
- 可靠处理异步任务、进度、失败和部分结果；超时先查结果，避免重复实例化。
- Skill 依据用户实际需求选择 AI 搭建或启用，交付生成应用及资源的真实链接与限制。

## 验收

覆盖发现、两种路径、异步结果、重试边界、目标一致性和权限错误。真实启用需独立且明确授权的测试目标，保留原有模板和业务应用。配置或 API 成功不等于生成应用可用，实际核对生成资源和页面。
