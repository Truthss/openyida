## 已验证方法

| 对象 | 查询方法 | 结果 |
| --- | --- | --- |
| 单日期 | `DOUBLE + DateField + is / is_not`，value 空字符串 | 空 [1,2,3]；有值 [4,5,6] |
| 区间整个未填 | `.start` 与 `.end` 都按 DateField 查询 is | [1,2] |
| 区间完整 | 两端都查询 is_not | [4,6] |
| 半填区间 | 开始已填、结束为空；反向组合 | [5]；[3] |
| 任一端已填 | 同步维护的已填端点数 gt 0 | [3,4,5,6] |
| 文本、多行文本 | TEXT + is / is_not | 空 [1,2,3,6]；有值 [4,5] |
| 数字 | DOUBLE + is / is_not | 空 [1,2]；有值 [3,4,5,6] |
| 单选、下拉单选 | ARRAY + is / is_not | 空 [1,2,3,6]；有值 [4,5] |
| 成员 | STRING + is / is_not | 空 [1,2,3,6]；有值 [4,5] |
| 附件、图片 | TEXT + is / is_not | 有值 [4] |
| 复选、多选 | 同步维护的选项数 eq 0 / gt 0 | 无选项 [1,2,3,6]；有选项 [4,5] |
| 子表整体 | 同步维护的行数 eq 0 / gt 0 | 无行 [1,2,3]；有行 [4,5,6] |

另外验证了成员 contains 的 userId 数组和区间嵌套数组范围查询。指南恢复时补查了子表整体 `TableField + TEXT + contains`，关键词“子表样本”命中 [4,5]；该值查询方法与子表行数空值筛选同时保留。

## 本次纠正的认识

1. 日期字段原生支持空值查询，不需要为了日期空值拉全量到前端过滤。
2. 日期区间按 `.start` / `.end` 查询；“两端完整”和“任一端已填”具有不同语义。
3. 多选通过 API 保存空数组后，存储空值条件不能代表业务是否选择；升级实例结构后也观察到这种差异。推荐已选数量。
4. 子表子字段空值查询表示存在匹配行，不包含没有行的主记录；子表整体推荐行数。
5. Canvas JS-API 接受条件数组；原技能将它限定为简单字典的说明已修正。
6. 历史实例填写新增字段时使用最新表单版本，并以回读结果判断成功；结构更新后即时成功响应曾未反映实际字段值。

部门、国家、地址、评分、流水号、关联表单、级联选择、时区日期未纳入本次实测，不加入通用空值映射。流程查询也不由本次普通表单结果推断。

原始 API 探针、字段回读及浏览器校验明细保存在本地任务目录 `project/.cache/openyida/empty-matrix/`；本报告仅保留合成样本序号，不包含成员 ID 或附件授权地址。
