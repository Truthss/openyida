# 自定义数据管理页

仅在用户明确要求自定义实现或目标已经是自定义页时使用。原生页支持的复杂权限、视图配置、关联、导入导出等不可悄悄省略；复杂管理优先保留原生承载。简单数据可采用下列结构，选择以任务为准，不是统一表格换色。

| 布局 | 工作方式 | 关键差异 |
| --- | --- | --- |
| 卡片目录 | 少量客户/资产档案浏览 | 多列卡片与侧边速览 |
| 分栏工作台 | 队列逐项处理 | 左队列右上下文，减少来回跳转 |
| 状态看板 | 跟进工单或阶段 | 按真实状态分列；拖拽改状态须另有业务授权 |
| 时间轴 | 发布排期或预约 | 日期主轴与分组，保留无日期记录 |
| 深绿总览 | 采购/订单工作区 | 深绿导航、黄绿主操作、摘要卡片与列表 |
| 橄榄清单 | 轻量台账 | 浅色侧栏、状态页签、无竖线斑马行、紧凑文字摘要 |

复用 `yida-canvas-custom-page` 和 `yida-canvas-data-binding` 的主题 Provider、真实表单查询和既有详情/新增机制。历史 JSX 保持对应运行时。不要为风格加“打开原生详情页”的备用按钮；原有打开方式不因美化而改变。

- 必须绑定实际 formUuid、fieldId、配置的状态选项，不能将截图的订单/支付业务强套到用户表单。
- 搜索、状态筛选、分页、刷新、加载/错误/空状态是真实查询；条件变化回第一页，勾选不跨不同结果误保留。
- 汇总只包含当前页时明确标注，不能把当前页数量/预算冒充全表汇总。不虚构同比、增长率或完成率。
- 导出按查询权限和明确范围执行，默认当前页/选中记录；CSV 转义并防公式注入，不绕过权限批量导出全表。
- 详情与新增沿用标准机制和已有业务链路；不要从跨域 iframe 读取未授权状态，不在测试中提交记录。
- 宽屏摘要/列表层次与窄容器重排共同设计；操作自然换行，表格内部横滚，不用隐藏业务列来假装响应式。

CLI 的 `generate` 仅输出**原生页**样式，不能将上述自定义布局 ID 传给 `--style`。自定义页按其源码流程实现和发布；“六类参考方向”不是六个已绑定用户业务的模板。
